01 / APPROACH

让上下文与行动，
留在同一个工作区。

CordiAct 是我们正在构建的原生 Android 产品。我们从 Android 出发，探索一种不把 AI 停留在聊天框里的工作方式。

01

围绕工作，而不只是对话

工作区组织会话、文件与工具，让每一次交流都有明确的工作范围。

02

连接能力，而非堆叠入口

模型适配、设备操作与执行后端通过统一契约协作，服务于具体任务。

03

行动有边界，过程可追踪

把权限、审批与执行策略作为基础设计，而不是在工具调用之后补上。

02 / BUILDING BLOCKS

一个运行时，
多种行动方式。

以下方向已在项目源码中实现相关模块，仍在持续完善。实际可用性取决于版本、设备权限及服务配置，不代表完整的稳定版承诺。

CONTEXT

工作区与会话

围绕工作区管理上下文、交互引用与工具范围，让协作有清晰的起点。

MODELS

多协议模型接入

适配 DeepSeek、Anthropic、Gemini、OpenAI 及兼容端点，按服务配置使用。

EXECUTION

设备与远程工具

文件、屏幕、浏览器、SSH 与 Termux 等能力通过工具层接入；部分需要额外授权。

CONTROL

审批与协作

通过执行策略、审批与子 Agent 模块，组织具有明确边界的工具协作。
